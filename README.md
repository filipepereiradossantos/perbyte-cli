# 💻 Perbyte CLI

Gerenciador de tarefas desenvolvido em **C++**, executado diretamente pelo terminal. O projeto permite cadastrar tarefas, definir prioridades e visualizar as atividades registradas.

Este projeto foi desenvolvido com finalidade acadêmica e de aprendizado, com foco na prática de lógica de programação, estruturas de dados e validação de entradas.

## 🛠️ Tecnologias

- C++
- Biblioteca padrão (`iostream`, `string`, `vector` e `limits`)
- Estruturas de controle e repetição
- Visual Studio Code
- Compilador GCC (g++)

## 📚 Funcionalidades

- Cadastro de tarefas com descrição.
- Definição de prioridade: alta, média ou baixa.
- Listagem das tarefas cadastradas.
- Validação de entradas do usuário.
- Menu interativo pelo terminal.
- Encerramento do programa pelo menu principal.

## 🧩 Como executar

**Pré-requisitos:**

- Compilador C++ instalado, como o GCC (`g++`).
- Terminal ou editor de código, como o Visual Studio Code.

**Compilar o programa:**

```bash
g++ main.cpp -o perbyte
```

**Executar no Windows:**

```bash
.\perbyte.exe
```

**Executar no Linux:**

```bash
./perbyte
```

## 🎯 Objetivo do projeto

O **Perbyte CLI** foi desenvolvido para aplicar, na prática, os fundamentos da programação em C++, por meio da criação de um gerenciador de tarefas executado pelo terminal.

O projeto reúne conceitos de lógica de programação, estruturas de dados, controle de fluxo e validação de entradas, contribuindo para o desenvolvimento das minhas habilidades técnicas.
